Why this extension?

Freshservice reauthentication can sometimes return the user to the home page or dashboard instead of the page that was open before the session expired. This extension keeps the page context in the browser and restores it after authentication succeeds.

It does not extend the session, bypass authentication, read credentials, or modify the SSO flow.
